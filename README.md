# Candles E-Commerce API (Backend)

A RESTful API built for the Candles E-Commerce platform. This project demonstrates clean architecture principles, modular design, and strict data typing.

## Architecture & Features
* **Separation of Concerns:** Logic is strictly divided into Controllers, Services, and Routes.
* **Data Validation:** Implemented using Data Transfer Objects (DTOs) for robust input handling.
* **Authentication:** Secure routing via custom middleware (`authMiddleware.ts`).
* **Modular Features:** Dedicated endpoints for Auth, Basket, Orders, Payments, and Products.

## Tech Stack
* Node.js
* TypeScript
